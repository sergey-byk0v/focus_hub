# Procrastination
**The best time to start is *now*.**

- Set a **5-minute timer** and just start
- Break the task into **3 tiny steps**
- Write down *why* you're avoiding it
- Do the hardest part first for **2 minutes**
- Ask a friend to hold you accountable

> "You don't have to be great to start, but you have to start to be great."

`function start() { return justDoIt(); }`

# Avoiding something
- Set a **5-minute timer** and just start
- Write down what's *bothering* you
- Break it into the **smallest possible step**
- Take a **2-minute breather** first

Then come back and do just **one** small thing.

# Work/Study
### Stay focused
- [Set a Pomodoro timer](https://pomofocus.io)
- **25 min** work / **5 min** break
- Review your **to-do list** first

> "Work expands so as to fill the time available for its completion."
> — Parkinson's Law

- Take *structured notes* — not just copy-paste
- Explain the concept to **someone else** (rubber duck!)

### Breaks matter
- Take a **5-minute break** after 25 minutes
- Walk away from the screen
- *Hydrate!*

# On background

- Use it as *white noise* for focus
